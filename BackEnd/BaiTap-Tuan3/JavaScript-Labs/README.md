## 6. Hướng dẫn truy cập các bài thực hành

**Trên GitHub Pages**

1. Mở trang chủ ở mục 3.
2. Ở phần **Các bài Lab**, bấm nút **Mở Lab 08 / 09 / 10** để vào bài đầu tiên của Lab đó.
3. Bấm **Xem tất cả bài** để mở danh sách và chọn từng Exercise hoặc Walkthrough.

**Trên máy tính**

1. Tải hoặc clone repository về máy.
2. Mở thư mục `JavaScript-Labs/` rồi mở `index.html` bằng trình duyệt (hoặc dùng Live Server trong VS Code).
3. Mở Console (F12) để xem kết quả các bài ở Lab 08.
